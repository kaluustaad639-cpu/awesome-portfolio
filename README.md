# Alex Chen - Portfolio Website

## 🚀 Overview

A modern, fully-responsive portfolio website built with HTML, CSS, and vanilla JavaScript. Features smooth animations, beautiful gradients, and an intuitive user experience.

## ✨ Features

- **Responsive Design** - Fully responsive and mobile-friendly
- **Smooth Animations** - CSS animations and transitions throughout
- **Modern UI** - Clean, professional design with gradient accents
- **Contact Form** - Functional contact form with validation
- **Scroll Navigation** - Active navigation highlighting on scroll
- **Projects Showcase** - Grid layout for featured projects
- **Skills Section** - Animated skill progress bars
- **Social Links** - Connected social media profiles
- **Performance Optimized** - Fast loading and smooth interactions

## 🎨 Sections

1. **Hero** - Eye-catching landing section with CTA buttons
2. **About** - Personal introduction with stats
3. **Projects** - Showcase of featured work with live demos and GitHub links
4. **Skills** - Technical skills with progress indicators
5. **Contact** - Contact information and message form
6. **Footer** - Footer with links

## 🛠️ Technologies Used

- HTML5
- CSS3 (Flexbox, Grid, Animations)
- Vanilla JavaScript
- Font Awesome Icons

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/kaluustaad639-cpu/awesome-portfolio.git
   ```

2. Navigate to the project directory:
   ```bash
   cd awesome-portfolio
   ```

3. Open `index.html` in your web browser or deploy to a hosting platform.

## 💡 Customization

### Colors
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary: #667eea;
    --secondary: #764ba2;
    --accent: #f093fb;
    /* ... other colors */
}
```

### Content
Update personal information in `index.html`:
- Name and title
- About section
- Projects details
- Skills and proficiencies
- Contact information

### Projects
Add or modify project cards in the "Projects" section with your own work.

## 📱 Responsive Breakpoints

- **Desktop** - 1200px and above
- **Tablet** - 768px to 1199px
- **Mobile** - Below 768px
